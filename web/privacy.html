PDF 도구 개인정보 처리방침

적용 대상: PDF 도구 웹판(GitHub Pages)과 Chrome 확장 프로그램. 시행일: 2026년 11월 4일.

수집하는 정보

PDF 도구는 사용자의 개인정보를 수집하지 않습니다. 이름, 메일 주소, 사용 기록, 방문 통계 같은 정보를 모으지 않으며, 쿠키나 분석 도구, 광고를 쓰지 않습니다.

불러온 파일의 처리

불러온 PDF와 이미지 파일은 사용자의 브라우저 안에서만 읽고 처리합니다. 파일과 그 내용은 어떤 서버로도 보내지 않습니다. 저장한 결과 파일은 브라우저의 다운로드 기능으로 사용자의 컴퓨터에 저장됩니다. 탭을 닫으면 불러온 파일은 프로그램의 메모리에서 사라집니다.

네트워크 사용

프로그램은 자기 자신을 이루는 파일(화면, 스크립트, 라이브러리)만 불러옵니다. 외부 서비스에 요청을 보내지 않습니다. Chrome 확장은 이 파일들을 확장 안에 모두 담고 있으며, 아무 권한도 요청하지 않습니다.

호스팅 서비스

웹판은 GitHub Pages에서 제공합니다. GitHub은 사이트를 제공하고 보안을 유지하기 위해 방문자의 IP 주소 같은 접속 기록을 남길 수 있습니다. 이 기록은 GitHub이 관리하며, PDF 도구의 개발자는 이 기록을 받지 않습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.

변경과 문의

이 방침이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다. 문의는 GitHub 저장소의 이슈로 남겨 주세요.

Privacy Policy (English)

Applies to the PDF Tool web app (GitHub Pages) and its Chrome extension. Effective November 4, 2026.

No data collection. PDF Tool does not collect, store, or share any personal or usage data. It uses no cookies, analytics, or ads.

Local processing. PDF and image files you open are read and processed only inside your browser. They are never uploaded or sent to any server. Results are saved to your computer through the browser's download feature.

Network. The app loads only its own files and makes no requests to third-party services. The Chrome extension bundles all of its files and requests no permissions.

Hosting. The web app is hosted on GitHub Pages. GitHub may log visitor IP addresses for security purposes, as described in the GitHub General Privacy Statement. The developer does not receive these logs.

Contact. Please open an issue at github.com/drybulk/pdf-tool.
