# PDF 도구

PDF 병합, 쪽 범위 추출, 쪽 단위 순서 편집(마우스 드래그)을 제공하는 tkinter 기반 GUI 프로그램입니다.
두 가지 판이 있습니다.

| 판 | 실행 파일 | 외부 라이브러리 | 차이 |
|---|---|---|---|
| 경량판 | `pdf_tool.py` | `pypdf` | 기본 기능 |
| 렌더링판 | `pdf_tool_render.py` | `pypdf`, `pypdfium2`, `Pillow` | 쪽 목록에 썸네일을 표시하고, 클릭한 쪽을 오른쪽에 크게 보여 줍니다. 쪽을 PNG, JPG 이미지로 저장할 수 있습니다 |

GUI는 파이썬에 기본으로 포함된 `tkinter`를 사용합니다.

## 설치와 실행

```
pip install -r requirements.txt
python pdf_tool.py
```

실행에는 `pdf_tool.py`와 같은 폴더에 있는 공통 모듈 `pdf_common.py`가 함께 필요합니다.

렌더링판:

```
pip install -r requirements-render.txt
python pdf_tool_render.py
```

렌더링판은 `pdf_common.py`와 `pdf_render.py`가 같은 폴더에 있어야 합니다. 기본 창 크기는 1200×750이며, 화면이 작으면 화면 안에 들어오도록 줄어듭니다.

검증한 환경은 Python 3.12, pypdf 5.9.0입니다.

## 기능

**페이지 추출 / 편집 / 병합** (탭 없이 한 화면입니다)
- 여러 PDF를 불러오면 목록 순서대로 이어 붙여 하나의 PDF로 저장합니다. 따로 있던 "PDF 병합" 탭은 이 화면으로 통합했습니다.
- 쪽 범위를 지정해서 불러옵니다. 예: `721-732`, `1-3, 10, 15-20`, `5-`(5쪽부터 끝까지), 비우면 전체. 쪽 번호는 PDF 뷰어의 쪽 번호 기준이며 입력한 순서가 유지됩니다.
- 쪽을 마우스로 끌어서 순서를 바꿀 수 있습니다. 끄는 동안 놓을 위치에 빨간 가로선이 나타나고, 마우스를 놓으면 그 위치로 옮겨집니다.
- Ctrl/Shift+클릭으로 여러 쪽을 선택해 함께 옮길 수 있습니다. 떨어져 있는 쪽들을 선택해 끌어도 놓은 위치에 원래 순서대로 모입니다. 목록 바깥으로 끌면 자동 스크롤됩니다.
- 쪽을 옮기면 옮긴 쪽이 화면에 보이도록 스크롤되고, 잠깐 주황색으로 강조됩니다.
- 선택 삭제, 위/아래 이동, 맨 위/맨 아래, 위치 지정 이동, 전체 선택, 목록 비우기를 지원합니다.
- 현재 화면의 순서 그대로 새 PDF로 저장합니다.
- 창 위쪽의 메뉴 막대(파일, 편집, 도움말)에서 불러오기, 저장, 실행 취소, 이동, 삭제 등을 할 수 있습니다. 실행 취소 기록이 없거나 선택한 쪽이 없으면 해당 항목이 흐리게 표시됩니다.
- 쪽 목록에서 마우스 오른쪽 버튼을 누르면 쪽 메뉴가 나옵니다. 선택한 쪽 위에서 누르면 선택이 유지되고, 선택하지 않은 쪽 위에서 누르면 그 쪽만 선택됩니다.
  - "이 파일의 쪽 모두 선택": 누른 쪽과 같은 PDF에서 불러온 쪽을 모두 선택합니다. 이어서 끌어 놓거나 "맨 위로"를 고르면 그 파일의 쪽이 원래 순서대로 한곳에 모이므로, 파일 단위로 순서를 바꿀 때 사용합니다.
  - 위로, 아래로, 맨 위로, 맨 아래로, 위치 지정 이동, 선택 삭제(렌더링판은 이미지로 저장도 있음)
- 저장할 때 원본 PDF의 북마크(목차)를 유지할 수 있습니다(기본값은 켬). 저장한 PDF에 들어 있는 쪽을 가리키는 북마크만 남고, 같은 쪽이 두 번 들어 있으면 처음 나오는 위치를 가리킵니다.
- 파일 이름으로 북마크를 추가하는 옵션이 있습니다(기본값은 끔). 같은 파일의 쪽이 이어지는 구간마다 그 첫 쪽에 하나씩 만들어지고, 원본 북마크는 그 아래에 들어갑니다.
- 본문의 인용 번호, 그림 번호 같은 링크는 원본과 같은 위치(쪽 안의 좌표)로 이동합니다. 여러 논문을 합칠 때 링크 이름이 겹쳐도 각 논문의 링크는 자기 논문 안의 위치로 이동합니다. 링크가 가리키는 쪽을 저장하지 않았다면 그 링크는 동작하지 않습니다.
- 저장 경로가 불러온 원본 파일과 같으면 저장하지 않습니다.

**렌더링판에서 추가되는 기능**
- 쪽 목록의 각 행에 썸네일을 표시합니다. 화면에 보이는 쪽만 그리고, 최근 300장을 보관합니다.
- 마지막으로 클릭한 쪽(키보드 위/아래 화살표로 옮긴 쪽 포함)을 오른쪽 미리보기 영역에 맞게 크게 보여 줍니다.
- 목록과 미리보기 사이의 경계를 마우스로 끌어서 두 영역의 폭을 조절할 수 있습니다.
- "이미지로 저장" 버튼(파일 메뉴와 우클릭 메뉴에도 있음)으로 쪽을 PNG 또는 JPG 파일로 저장합니다. 선택한 쪽 또는 목록 전체를 고르고, 해상도(72, 150, 200, 300 DPI)와 JPG 품질(1~95)을 정한 뒤 저장할 폴더를 선택합니다.
  - 파일 이름은 `원본이름_p0721.png`처럼 원본 쪽 번호를 씁니다. 같은 쪽이 목록에 두 번 있으면 `원본이름_p0721_2.png`처럼 번호를 붙입니다.
  - 같은 이름의 파일이 폴더에 이미 있으면 덮어쓸지 한 번 묻습니다.
  - JPG 저장에는 Pillow가 필요합니다. Pillow가 없으면 PNG만 고를 수 있습니다.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+O | PDF 불러오기 |
| Ctrl+S | 새 PDF로 저장 |
| Ctrl+Z | 실행 취소 (최대 100단계) |
| Ctrl+Y, Ctrl+Shift+Z | 다시 실행 |
| Ctrl+A | 전체 선택 |
| Delete | 선택 삭제 |

## 테스트

```
pip install -r requirements.txt -r requirements-dev.txt
xvfb-run -a python tests/test_page_tab.py   # Linux. 화면이 있는 환경에서는 xvfb-run 없이 실행
xvfb-run -a python tests/test_undo.py
xvfb-run -a python tests/test_common.py
xvfb-run -a python tests/test_menu.py
python tests/test_merge.py

# 렌더링판 (pip install -r requirements-render.txt 필요)
xvfb-run -a python tests/test_render.py
xvfb-run -a python tests/test_image_export.py
```

Linux에서는 `python3-tk`와 `xvfb`가 필요합니다.

렌더링 속도는 `python tools/bench_render.py 파일.pdf [--pages 100]`으로 측정할 수 있습니다. 썸네일, 미리보기, 200/300 DPI 렌더링의 쪽당 시간을 출력합니다. 각 쪽을 처음 그리는 시간을 따로 보여 주고, 시간이 가장 길었던 쪽 번호와 저장용 PNG를 만드는 시간도 함께 출력합니다.
